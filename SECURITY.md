# Security policy

Report suspected vulnerabilities privately through the repository's GitHub Security advisory flow. Do not open a public issue for a credential exposure, authentication bypass, cross-organization access issue, or supply-chain concern.

Include a minimal reproduction, affected version, impact, and any suggested mitigation. We will acknowledge receipt, investigate, and coordinate a fix before public disclosure.

Never include real credentials, WorkOS sessions, API keys, personal data, or production deployment details in a report.

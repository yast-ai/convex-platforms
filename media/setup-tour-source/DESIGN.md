# Setup tour design

Warm paper background, charcoal type, and rust accents continue the repository walkthrough language. Dashboard captures sit in framed cards with a persistent provenance chip: **ACTUAL DASHBOARD STILL**, **SETUP ILLUSTRATION**, or **LOCAL UI MOCK**. The composition uses quiet hard cuts and short upward reveals; the evidence label stays visible longer than the headline.

Typeface: bundled IBM Plex Sans and Plex Mono. Contrast: charcoal `#20231f` on paper `#f7f3ea`; rust is used only for accents and labels.
